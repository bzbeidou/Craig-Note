### stage的概念

在ResNet论文中，网络被分成了几个大阶段（stage），每个stage中包含若干个残差块（Blocks），然后，然后每个Block里会有卷积层，所以并不是每层有残差链接，而是每个Block之间右参茶链接

特点是：

- **同一个 stage 里**：输入特征图的空间大小（H×W）和通道数（C）保持不变。
- **跨 stage**：特征图的空间分辨率缩小一半（H/2, W/2），同时通道数翻倍（C×2）。

**（1）为什么一个stage里要有多个残差块？**

因为单个残差块（2~3 层卷积）对输入的处理能力有限。

- 一个 block 只能在保持输入分辨率的情况下，稍微提取一下新特征。
- 多个 block 堆叠在一起，相当于对同样大小的特征图做多次处理 → 提取更丰富的特征。

所以设计时：

- 一个 stage = 多个残差块，保证在当前分辨率下充分学习特征。
- 然后才下采样进入下一个 stage，继续提取更抽象的特征。



ResNet-18 的结构：

1. **conv1**（输入层）：7×7 卷积 + 最大池化 → 输出 56×56，通道 64。
2. **conv2_x（stage 1）**：2 个残差块（每个有 2 个 3×3 卷积），输出 56×56，通道 64。
3. **conv3_x（stage 2）**：2 个残差块，输出 28×28，通道 128。
4. **conv4_x（stage 3）**：2 个残差块，输出 14×14，通道 256。
5. **conv5_x（stage 4）**：2 个残差块，输出 7×7，通道 512。
6. 全局平均池化 + 全连接层。

可以看到，每个 stage 内部通道数不变，空间分辨率不变。
 stage 之间才会发生下采样（通常是第一个 block 的 stride=2）。



**（2）为什么同一个Stage能保持56*56不变呢？**

因为一开始做了padding,拓展了两维的0，然后经过卷积之后就不会变小了，而且可以保证提取到边缘的特征



**（3）为什么stage之间会变小成二分之一呢 这就是下采样的结果**  

- 什么是下采样   其实就是把维度变小的方法

分别有两种方式

**卷积下采样**：卷积的 stride > 1（常用 stride=2），这样卷积核每次滑动跳 2 个像素 → 输出尺寸减半。

**池化 (Pooling)**：最大池化/平均池化（如 2×2 池化，stride=2）。



在ResNet里一般是通过调整stride来实现的，从1改到2，然后处理之后就能降低维度了。



**（3）通道数翻倍是什么意思？**

其实就是特征图数量翻倍了，比如在stage1里几个卷积层卷积核的个数都是20，那么输出的结果也都是20个特征图，然后从stage1到stage2卷积核的个数变为40，然么输出也变为40，这就翻倍了。



这个翻倍操作是在哪个卷积层实现的呢？

是在下一个stage的第一个卷积层实现的，比如从stage1到stage2，那么从stage1出来之后应该仍然是50层，56*56，然后经过stage2的第一个残差块，宅这里做下采样以及通道翻倍的工作，实现分辨率减半和卷积核数量增加的效果

**（4）这样又带来新的问题不是吗**

进入新 stage 的第一个残差块（block）时，**维度确实会发生变化**，导致不能进行残差链接。

- 进入stage2之前 输入维度`56x56x64`

- 进入stage2之后的第一个block

	- 卷积路径

		- 第一个卷积：stride = 2，空间尺寸减半并通道数增加`56×56×64 → 28×28×128`
		- 第二个卷积就是普通卷积stride=1，，然后就是保持不变`56×56×64 → 28×28×128`

		

		**但是从外面来的输入就不能进行残差链接不是吗？维度不同**

		所以对外边来的分支输入也需要建一个1*1的卷积核，但是stride = 2，这样也把输入从`56x56x64`转变为`28x28x128`
