#### 引

输入归一化和BatchNorm的归一化有什么区别呢？又有什么联系呢？

**答案是输入归一化和BatchNorm是完全两种不同的归一化方式**

**区别**

- 输入归一化仅仅是在输入时对数据进行简单归一化的过程，这个归一化数据是在训练过程就由人给定下来的，其中也没有可学习参数，训练和推理的时候就都用这个归一化数据进行归一化
- 输入归一化输入预处理的一部分

**共性**

- 基本没什么共性，唯一的共性就是都是归一化，让数据限制在一定的返回，减少反向传播时导致的梯度浮动过大



**一句话：输入归一化和BatchNorm是完全两种针对不同场景的归一化方式**



#### 1、输入归一化mean/scale是模型的训练者定的

**对比于BatchNorm：BatchNorm的mean就是数据的均值，scale就是方差，都是由训练数据决定的，通过不断的批次输入不断地变化，最终得到一个具有对所有数据有普适性的mean和scale**

- 当然输入归一化的mean和scale也是由数据统计来的，但是是直接外部自己计算的，BatchNorm是在训练过程中由模型计算的

**对比完了，我们来看输入归一化本身**

推理时我们必须严格复现当时训练的归一化，否则精度会掉得很厉害。

以ResNet的预处理中的输入归一化为例：

```
mean = [0.485, 0.456, 0.406]
scale = [1/0.229, 1/0.224, 1/0.225]
```

其实是来源于 **ImageNet 数据集的统计结果**。

训练 ResNet 时，ImageNet 数据的像素被统计出：

- R 通道平均值 ≈ 0.485
- G 通道平均值 ≈ 0.456
- B 通道平均值 ≈ 0.406
	 （这些值是以 0~1 归一化后计算的）

同时，标准差分别是：

- R 通道标准差 ≈ 0.229
- G 通道标准差 ≈ 0.224
- B 通道标准差 ≈ 0.225

因此训练时定义的归一化操作是：

 x‘ = (（x/255）-mean)/std;



#### 2、不同模型的输入归一化公式不同，有的不减均值只做缩放等等

**对比于BatchNorm,BN的公式都是完全一致的**

这里我们只要了解ResNet和YoLOv5就可以了。

| 模型                      | 训练输入范围 | 归一化公式            | 说明                                   |
| ------------------------- | ------------ | --------------------- | -------------------------------------- |
| **ResNet / VGG**          | [0, 1]       | (x - mean) / std      | 保持零均值、单位方差（传统 CNN）       |
| **YOLOv5 / SSD**          | [0, 1]       | x / 255               | 只缩放，不中心化（速度优先）           |
| **MobileNet / Inception** | [-1, 1]      | x' = x / 127.5 - 1    | 激活函数常用 ReLU6，需要输入在 [-1, 1] |
| **CLIP / ViT**            | [-1, 1]      | (x / 255 - 0.5) / 0.5 | Transformer 模型风格，输入零均值       |



#### 3、正是因为训练时都是用的输入预处理后的数据，那么推理的时候肯定也要经过这个完全一致的过程，否则精度肯定对不上
