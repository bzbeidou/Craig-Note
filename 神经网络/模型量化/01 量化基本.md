#### 1、什么是模型量化

把神经网络中原本用高精度（如 float32）的**权重**和**激活值**，用低精度（如 int8、int4）来表示。

这样就是为了减少模型体积并提升计算速度，但是精度会下降

**举例：**

有个浮点数权重如下：

```
w = 0.3456
```

我们用int8表示的时候，int8的范围是[-128, 127]

那我们要找到一个比例（scale）来映射float->int:

```
q = round(w/scale)
```

解量化（恢复）时：

```
w约等于q*scale
```

如果scale = 0.01

```
q = round(0.3456 / 0.01) = 35
解量化后 w' = 35 * 0.01 = 0.35
```

就看到：虽然有微小误差，但值被低精度整型近似表示了。



#### 2、量化的主要种类

实际上这些种类都是量化时必须的，比如有一个模型我们采用PTQ，然后选择W4N6,就是对权重做int4量化，对激活值做int6量化，然后选择对称量化，这就能套公式了，就是量化的基本过程



- 按阶段分分为 后量化 PTQ 以及 训练时量化QAT

| 类型                                   | 说明                                        | 示例                     |
| -------------------------------------- | ------------------------------------------- | ------------------------ |
| **PTQ（Post-Training Quantization）**  | 训练好 float 模型后再离线量化（常用于部署） | TensorRT / TPU-MLIR 常用 |
| **QAT（Quantization-Aware Training）** | 在训练过程中就模拟量化误差，提高精度        | PyTorch QAT、TFLite QAT  |

- 按精度位宽如下

| 类型            | 说明                                               | 示例          |
| --------------- | -------------------------------------------------- | ------------- |
| **INT8**        | 最常见，速度快，精度损失小                         | 工业主流      |
| **INT4 / INT2** | 更极端压缩，常用于边缘设备                         | 精度损失更大  |
| **FP16 / BF16** | 半精度浮点，不算严格的整数量化，但也属于低精度计算 | 高端 GPU 常用 |

- 按作用类型可以分为如下: 其中我们说的W4N6就是在这里面

| 类型                                    | 说明                            | 示例           |
| --------------------------------------- | ------------------------------- | -------------- |
| **按作用范围**                          |                                 |                |
| **权重量化（Weight Quantization）**     | 只量化权重参数                  | 存储空间下降   |
| **激活量化（Activation Quantization）** | 量化中间特征值                  | 推理速度加快   |
| **对称量化（Symmetric）**               | 量化范围对称 [-a, a]            | 常见于硬件优化 |
| **非对称量化（Asymmetric）**            | 范围 [a, b]，适应非对称数据分布 | 常用于激活值   |



#### 3、常见的量化公式

**对称量化**

```
q = clamp(round(x / scale), -127, 127)
x ≈ q * scale
```

**非对称量化**

```
q = clamp(round(x / scale) + zero_point, 0, 255)
x ≈ (q - zero_point) * scale
```



#### 4、再讲一下W4N6

这就是量化配置

其中：

- **W** = Weights（权重量化 bit 数）
- **N** = Activations（即中间特征值 / 激活量化 bit 数）

| 名称               | 含义                  | 说明                     |
| ------------------ | --------------------- | ------------------------ |
| **W8A8**（或W8N8） | 权重 8bit，激活 8bit  | 最常见的 INT8 量化配置   |
| **W4A8**           | 权重 4bit，激活 8bit  | 混合精度量化             |
| **W4A6 / W4N6**    | 权重 4bit，激活 6bit  | 权重更低，激活略保留精度 |
| **W2A8**           | 权重 2bit，激活 8bit  | 极低精度权重             |
| **W8A16**          | 权重 8bit，激活半精度 | 常用于部分算力受限硬件   |

有些人写 **W4N6**，有些写 **W4A6**，
 “A” 和 “N” 都指 activations（N来自Neural Activations），意思一样。



**为什么会出现这种混合配置？**

不同的部分对精度的敏感度不一样：

- **权重（Weights）** 是固定参数，4bit 通常已经够表达；
- **激活值（Activations）** 在推理时变化大，若量化太狠（如4bit），可能会造成较大精度损失；
- 所以工程上常选 **W4N6 或 W4N8**，在节省算力的同时保留一部分激活精度。

**W4N6 对应的量化范围**

| 项目          | 位宽 | 表示范围              | 可表示的整数个数 |
| ------------- | ---- | --------------------- | ---------------- |
| **权重 (W4)** | 4bit | [-8, 7]（有符号）     | 16               |
| **激活 (N6)** | 6bit | [0, 63]（一般无符号） | 64               |

也就是说：

- 权重是对称量化（symmetric）
- 激活多是非对称量化（asymmetric）



#### 5、激活值不是动态的吗？量化的作用在哪？

回顾一下激活值是什么？

**激活值（Activation）** 是指每一层计算的**中间结果**，也就是：

`Activation = f(Wx + b)`

例如在 ResNet50 的一个卷积层中：

```
Input → Conv(weight) → BN → ReLU → Output
```

这里的 **Output** 就是激活值，也就是下一层的输入。



**权重vs激活**

| 项目           | 权重（Weights）          | 激活（Activations）        |
| -------------- | ------------------------ | -------------------------- |
| 性质           | 固定参数（训练好后不变） | 动态数据（每次推理时不同） |
| 存储           | 存在模型文件里           | 不保存，只在推理中临时产生 |
| 量化意义       | 减小模型体积             | **减少计算量和内存带宽**   |
| 是否可提前计算 | 可以离线量化             | 不能离线，只能推理时量化   |



例如`output = Conv2D(input, weight)`

- 如果权重是 int8，但输入（激活值）仍是 float32，
	 那卷积计算就得 float×int8 → float，
	 **硬件根本没法用整数矩阵乘法加速。**

而如果：

- 权重 int8
- 激活也 int8

那么计算就变成：

```
int8 × int8 → int32 → float（再scale回来）
```

**所以激活值量化的意义就在于让模型可以直接用到硬件TPU的整数运算单元**





**因为激活值是动态的，所以我们无法直接离线量化。这个后面会讲一下详细的步骤**
