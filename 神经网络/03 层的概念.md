**一层包括三个方面：**

- 权重矩阵，就是加权和（上一层到这个一层每个神经元的链接系数）
- 偏置向量（每个神经元的偏置）
- 激活函数（非线性变换）

思考回顾一下我们学的MLP，很明显每一层就是包括加权和+偏置以及激活函数的部分



**CNN中的层也一样吗？**

CNN 的层也可以用类似概念理解，但稍微做了扩展：

| 层类型       | 层内操作是什么                                               |
| ------------ | ------------------------------------------------------------ |
| **卷积层**   | 每个卷积核 = 权重矩阵（小窗口），对局部做加权和 + 偏置，然后过激活函数 |
| **池化层**   | 不存在权重和偏置，只是做最大/平均下采样                      |
| **全连接层** | 和 MLP 一样：加权和 + 偏置 + 激活函数                        |
| **Dropout**  | 不改变权重，只是训练时随机丢弃部分神经元                     |
