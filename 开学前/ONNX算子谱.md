#### 2、怎样有效地处理复杂的算子

**（1）分组算子，有限找重点部分**

优先支持主计算类和常见数据准备类，其余逐步补充。

| 类别         | 代表算子                                   | 作用               |
| ------------ | ------------------------------------------ | ------------------ |
| 主计算类     | `MatMul`, `Conv`, `Add`                    | 执行数值计算       |
| 数据准备类   | `Reshape`, `Transpose`                     | 数据形状调整       |
| 控制结构类   | `Slice`, `Gather`, `Where`                 | 控制输入路径、选择 |
| 常量与构图类 | `Constant`, `Shape`, `Unsqueeze`, `Concat` | 构建辅助张量       |

**（2）把Shape推理和执行分离**

每种算子都定义清楚：

- **输入 shape 怎么来**
- **输出 shape 怎么推理**
- **哪些参数是 Constant（权重）**
- **哪些输入来自模型动态输入（比如 input_ids、xq）**

**（3）Constant不是垃圾   ----是关键**

提供权重、参数（比如：位置编码的频率表、卷积核、bias、norm参数等）

提供静态 shape 信息（配合 `Gather` 和 `Shape` 推导）

是构建图形结构的基础（Concat 连接 shape vector）

**（4）遇到不明确的形状怎么办**

**追溯源头**：ONNX 中的 `Shape`, `Gather`, `Slice` 一般来源于其他张量的 shape 或 `Constant`

**静态推导**：比如用 `input_ids.shape = (1, 128)` 来反推 downstream 节点的大小

**模拟运行**：你可以构建一个 mini runtime，在加载模型时用 `numpy` 模拟执行前几层，得到中间结果

**导入真实数据**：用 PyTorch 或 ONNXRuntime 推一次，dump 出中间 tensor shape，辅助你的推理系统训练

#### 4、子图划分

| 子图模块                 | 功能说明                              | 通常起始算子                 | 特征                             |
| ------------------------ | ------------------------------------- | ---------------------------- | -------------------------------- |
| `embedding` 部分         | input_ids → embedding → hidden_states | `Gather`                     | 起始输入为 `input_ids`           |
| `attention_mask` 部分    | 用于构造 attention bias               | `Shape` / `Cast` / `Sub`     | 输入通常是 mask 或 input_ids     |
| `RoPE` 部分              | 对 Q/K 向量加位置编码                 | `Reshape` / `Concat` / `Mul` | 有复数模拟结构、`(x,y)` → `x+iy` |
| `QK MatMul` 部分         | Self-Attention 核心相似度计算         | `MatMul(Q,K^T)` / `Softmax`  | 有 `Transpose`、`Softmax` 等     |
| `V 路径` 部分            | 得到 attention 输出                   | `MatMul(Softmax, V)`         | 接收 softmax 输出，与 `V` 相乘   |
| `MLP` / `Feedforward`    | Transformer FFN部分                   | `GELU` / `MatMul` / `Add`    | 通常是两层 `MatMul` 夹激活       |
| `残差连接` + `LayerNorm` | 每层都有残差跳跃结构                  | `Add` / `LayerNormalization` | 作用在每个子模块之后             |
| `输出层`                 | 最后的 `lm_head` 或 `projection`      | `MatMul`, `Add`              | 输出 logits                      |

#### 5、部分算子作用

**（1）Reshape  改变张量形状，对比下面的Transpose**

```
输入(2, 4)
[[1, 2, 3, 4],
 [5, 6, 7, 8]]

输出(4, 2)
[[1, 2],
 [3, 4],
 [5, 6],
 [7, 8]]

这里要注意这个改变形状并不是行列互换，实际上是把所有算子展平排在一起再进行划分，可以看到输出依然是12345678
```

应用：把 Linear 输出 `(batch, seq_len, hidden_size)` 变成 `(batch, seq_len, num_heads, head_dim)`

**（2）Transpose  交换张量的维度顺序  这就是转置T**

```
输入：
x = [[1, 2, 3],
     [4, 5, 6]]
    
输出：
[[1, 4],
 [2, 5],
 [3, 6]]
 就是转置
```

应用： Self-Attention 中 `QK^T` 的核心操作

**（3）Shape  就是获取输入张量各个维度元素数量信息，然后放到一个数组里存储**

```
X.shape = (2, 3, 5)
Y = Shape(X)
Y = [2, 3, 5]    # 一个 1D 向量
Y.shape = (3,)   # shape 本身是 1D，长度为 3

这里X张量本身是一个(2, 3, 5)的三维张量，用Shape获取其信息，然后放到了一个一维数组Y里存储，Y本身就是一个一维张量，类似数组来存储X的张量信息
```



**（4）Slice片   就是裁剪出来一个切片**

```
输入：
x = [[1, 2, 3, 4],
     [5, 6, 7, 8]]
 Slice(start=[1], end=[3], axes=[1]) 表示在 axis=1 上裁剪第 1 到第 3 个元素（不包括3）
输出：
[[2, 3],
 [6, 7]]

```

应用：对向量做分割（比如 RoPE 中把 `(cos, sin)` 拆成两半）

**（5）Concat   就是拼接操作**

```
输入：
A = [[1, 2],
     [3, 4]]      shape = (2, 2)

B = [[5, 6],
     [7, 8]]      shape = (2, 2)
在 axis=1 上拼接
输出：
[[1, 2, 5, 6],
 [3, 4, 7, 8]]    shape = (2, 4)

```

应用：合并多头结果

**（6）Gather收集 用来提取输入张量中指定维度的信息，可以看作是张量的索引（如同数组索引）**

```
Gather(data, indices, axis)

这里三个数据，在onnx计算图中data就是输入，indices和axis则会在这个Gather算子上展示
```

`data`: 输入的张量

`indices`: 要提取的位置索引，可以是标量或张量

`axis`: 指定在哪个维度上提取（默认是 0）

```
data = [[10, 11], [20, 21], [30, 31]]  
indices = [2, 0]                       
axis = 0

output = Gather(data, indices, axis=0)
输出:
output = [[30, 31], [10, 11]]       
就是在第axis = 0维上取了indices中第二个和第0个元素，也就是[30, 31], [10, 11]
```

**（7）Unsqueeze 在指定位置增加维度，可以用于标量变张量、增加维度等**

| 操作                        | 输入 Shape | 操作       | 输出 Shape |
| --------------------------- | ---------- | ---------- | ---------- |
| `Unsqueeze(x, axes=[0])`    | (3,)       | +1维在最前 | (1, 3)     |
| `Unsqueeze(x, axes=[1])`    | (3,)       | +1维在中间 | (3, 1)     |
| `Unsqueeze(x, axes=[0, 2])` | (3,)       | +两维      | (1, 3, 1)  |

**(7)Range 就是python中的range操作**

`Range` 操作的基本形式：

1. **起始值**（`start`）：序列的开始值。
2. **结束值**（`limit`）：序列的结束值（不包括）。
3. **步长**（`delta`）：每次递增的步长。

```
成从 0 到 10（不包括 10）
start = 0;
end = 10;
step = 2;
那么得到
[0,2,4,6,8]
当然是一个一维张量，形状是(5,)
```

**(8)Constant 在节点中是常量或者常张量**

**有时Constant不会出现，但是在其他节点依然有constant输入，为什么？**

实际上可以以属性的形式存储在节点内部。这些常量值通常通过节点的 `attribute` 字段传递，而不是作为节点的常规输入。

#### 6、onnx图中的Reshape一般有两个输入，是什么

```
Node: Reshape_1803 (Reshape)
  🔹 Input 0: onnx::Reshape_399, shape=(1,), dtype=int64
  🔹 Input 1: onnx::Reshape_431, shape=(4,), dtype=int64
  🔸 Output 0: onnx::Add_432, shape=(1, 1, 1, 1), dtype=int64

```

**input0是要修改形状的输入，Input1是修改标准**

这里就是把一个一维向量分成了4维,   **注意(1,)就是一个一维张量，同时他也只有一个元素，(1, 1, 1, 1)代表一个四维张量，但是只有一个值嵌套了四层**

```
原始数据：
    [42]           -> shape: (1,)
reshape 成：
    [[[[42]]]]     -> shape: (1, 1, 1, 1)

```

| 张量                   | shape          | 含义                        |
| ---------------------- | -------------- | --------------------------- |
| `np.array(42)`         | `()`           | 标量，没有维度，1个值       |
| `np.array([42])`       | `(1,)`         | 一维，1个元素               |
| `np.array([[42]])`     | `(1, 1)`       | 二维，1行1列                |
| `np.array([[[[42]]]])` | `(1, 1, 1, 1)` | 四维，只有一个值但嵌套了4层 |

**补充理解（128，4096）这种只是2维张量，但是实际上它代表着128个4096维向量，所以4096也就被称作是隐藏维度，高维空间根本不能想象出来**







#### 7、图中常见的算子的axis和axes是什么

很相似，主要就是标明当前算子对维度的操作

**`axis`**：单个整数，比如指定在哪个维度增加一个新维度。

**`axes`**：列表或数组，比如指定在哪些维度上增加一个新维度，可以同时增加多个维度。
