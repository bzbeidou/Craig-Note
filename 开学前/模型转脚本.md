1、看懂mldel_transform.py

**就是程序的起点：**将用户提供的预训练模型（如 ONNX、TFLite 等），统一转换为 MLIR（中间表达）格式，作为后续量化、优化和代码生成的起点。

（1）代码结构

**1）命令行参数**

```python
parser = argparse.ArgumentParser(...)
parser.add_argument("--model_name", ...)
parser.add_argument("--model_def", ...)
parser.add_argument("--input_shapes", ...)
...
args = parser.parse_args()
```

部分定义了用户可以传入哪些参数，比如：

- `--model_name`：模型名
- `--model_def`：原始模型文件（比如 onnx 文件）
- `--input_shapes`：输入张量的 shape（必须指定！）
- `--mlir`：输出的 mlir 文件名

**2）模型加载+统一入口处理**

```python
from tools.model_transformer import model_transform
model_transform(args)
```

这里 **真正干活的逻辑在 `model_transformer.py`**，也就是这个文件起的是 **参数传递 + 路由调度作用**

**3）支持多种前端框架**

`model_transform.py` 不直接处理 ONNX/TFLite，而是调用专门的转换器（如 OnnxConverter、TFLiteConverter），这些定义在：

```
python/
  ├─ tools/
  │   └─ model_transform.py  ← 当前文件
  └─ transforms/
       ├─ onnx_transform.py
       └─ tflite_transform.py

```

from utils.mlir_shell import *

常见函数如 `run_mlir_opt(...)`、`run_mlir_translate(...)`

```python
from utils.mlir_parser import *
```

**解析 MLIR 文件结构的工具类**

- 比如可以提取输入输出 tensor 名称、shape、type
- 有助于分析 MLIR 中是否符合预期、自动填补信息等

（3）各部分详解

**执行入口**

```py
if __name__ == '__main__':
    args = parser.parse_args()
    model_transform_func(args.model_name, args.model_def, args.input_shapes, ...)

```

**主逻辑函数  model_transform_func(...)  通常包含以下步骤**

```py
def model_transform_func(...):
    # 1. 构造参数对象 args
    # 2. 拿到 transformer 对象（调用 get_model_transform(args)）
    # 3. 调用 transformer.run()
    # 4. 输出转换后的 mlir 文件

```

 **get_model_transform(args):转换器选择器**

也就是根据传入的类型来选择转换器

```py
def get_model_transform(args):
    if args.model_type == "onnx":
        return OnnxTransformer(args)
    elif args.model_type == "tflite":
        return TFLiteTransformer(args)
    ...

```

**各个 Transformer 类（重点是 `OnnxTransformer`、`TFLiteTransformer`）**

**真正负责把模型解析、转换为 MLIR 格式的核心模块**。结构上都继承自一个通用的 `ModelTransformer` 或 `BaseConverter`，都实现了类似方法：

```python
class OnnxTransformer(ModelTransformer):
    def __init__(self, args):
        ...
    def run(self):
        # 加载 onnx 模型
        # 构造 MLIR
        # 调用 pymlir/IRBuilder 构建 graph
        # 保存 MLIR 文件
```

**`ModelTransformer`：抽象基类 / 父类**

这个类定义了所有 Transformer 的通用接口，例如：

```py
class ModelTransformer(metaclass=abc.ABCMeta):
    def __init__(...): ...
    @abc.abstractmethod
    def run(self):
        pass

```

Python自带的解析命令行参数的类

这个就是用来方便命令行工具使用的，只需要掌握就行，重点掌握 `.add_argument()` 和 `.parse_args()` 的使用，前者设置一些参数的名称、必要性、描述等，后者则是获取到这些通过命令行传入的参数

```py
import argparse

# 创建解析器对象
parser = argparse.ArgumentParser(description="示例程序")

# 添加命令行参数
parser.add_argument('--name', type=str, required=True, help="你的名字")
parser.add_argument('--age', type=int, required=False, help="你的年龄")

# 解析参数
args = parser.parse_args()

# 使用参数
print("你好，{}！".format(args.name))
if args.age:
    print("你已经 {} 岁了！".format(args.age))
else:
    print("你没有告诉我你的年龄哦！")

```

**使用**

```
// 命令行
python hello.py --name 小王 --age 18
```

**输出：**

```
你好，小王！
你已经 18 岁了！
```
