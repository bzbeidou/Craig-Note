

## Python

```
test/
├── test1.py
├── test2/
│   ├── __init__.py
│   └── test3.py
```

**python中包和模块的区别**

| 名称 | 定义                                             | 举例                                    |
| ---- | ------------------------------------------------ | --------------------------------------- |
| 模块 | 任何一个 `.py` 文件就是一个模块（module）        | `test1.py` 是一个模块                   |
| 包   | 含有 `__init__.py` 文件的文件夹叫做包（package） | `test2/` 里如果有 `__init__.py`，就是包 |

**几个重要原则：**

**（1）要 import 某个 py 文件，必须写全路径到 py 层**（比如 `import test2.test3`）。

**（2）不能 import 文件夹，除非它是包（含有 `__init__.py`）**。

**（3）顶层文件夹不应该直接 import**，而是要加入到 `PYTHONPATH` 中，让它作为搜索路径。
