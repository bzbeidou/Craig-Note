## 1 广播对齐的规则   忘了

1. **从最后一维开始对齐**
2. 对应维度 **必须满足以下条件之一**：
	- 左边维度等于右边维度
	- **其中一个维度为 1**
3. 如果都不为 1 且不相等 → 不兼容，会报错

**继承体系**

```
Attribute（基类）
├── IntegerAttr   // 整数
├── FloatAttr     // 浮点数
├── StringAttr    // 字符串
├── ArrayAttr     // 属性数组
├── DenseElementsAttr // 张量/数组常量
└── ...           // 其他特殊类型

```

举例一个MLIR Op

```
%0 = "tpu.Add"() { inputs = ["x","y"], outputs = ["z"], version = 2 } : () -> ()
```

这里仅仅是字符串，但是到了c++里就成为了一个个的对象，如下

- "inputs"` → `ArrayAttr

	 每个元素 → `StringAttr` ("x", "y")

- "outputs"` → `ArrayAttr
- "version"` → `IntegerAttr

**这里就是说到了c++里inputs这个属性对应的一个对象就是ArrayAttr类的，然后其中的"x"则是对应着StringAttr的，套娃**

## 3 、每个Op都有的getInputs()方法

这里就是td文件生成的getInputs()方法，返回的一个 **`operand_range` 对象**，里面则是保存了当前Op的所有

**复习：**

**Operand**（操作数） = 这个 Op 的一个输入值，操作数在c++里的形式是 `mlir::Value` 类型，通常来自别的Op的输出，operand_range这个对象则存储当前Op的所有输入Operand

**举例**

假设Op如下，还是以AddOp为例，实际上每个Op都有的

```
%0 = "tpu.add"(%a, %b) {attr1 = ...} : (tensor<4xf32>, tensor<4xf32>) -> tensor<4xf32>
```

解释：

- `%0` → `AddOp` 的输出
- `%a` 和 `%b` → `AddOp` 的两个输入

在c+里如下

```c++
AddOp addOp = ...;  // 拿到 IR 中的那个 "tpu.add" 节点

auto inputs = addOp.getInputs(); // 这是 operand_range 对象

for (mlir::Value v : inputs) {
    v.dump(); // 打印 Value 信息
}

```

很明显这里通过getinputs方法获取了输入operand，然后遍历了其中的operend，也就是Value的内容

## 1.InferenceParameter 里面一般存储输入以及推理后的输出，这个结构体被作为参数传播。

```c++
#include <vector>
#include <iostream>

struct InferenceParameter {
    std::vector<float *> inputs;
    std::vector<float *> outputs;
    void *handle = nullptr;
};

// 模拟一个 Op 的推理函数
void AddOp_inference(InferenceParameter &param) {
    float *input0 = param.inputs[0];
    float *input1 = param.inputs[1];
    float *output = param.outputs[0];
    for (int i = 0; i < 3; ++i) {
        output[i] = input0[i] + input1[i];
    }
}

int main() {
    float a[3] = {1, 2, 3};
    float b[3] = {4, 5, 6};
    float c[3] = {0, 0, 0};

    InferenceParameter param;
    param.inputs.push_back(a);      // 把输入张量 a 放进去
    param.inputs.push_back(b);      // 把输入张量 b 放进去
    param.outputs.push_back(c);     // 输出张量 c

    AddOp_inference(param);         // 调用推理函数

    std::cout << "Output: ";
    for (int i = 0; i < 3; ++i) {
        std::cout << c[i] << " ";
    }
    std::cout << std::endl;
    return 0;
}
```
