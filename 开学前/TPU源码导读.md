# 2、先学python文件夹内的内容

## 2.1 为什么？

TPU-mlir核心是用C++写的，包括dialect这些，但是却是通过python加载到模型然后进行编译的，也就是写的c++代码有接口链接到python代码，所以真正使用是从python开始，从高层开始学习比较容易理解



## 2.2 文件内容

| 目录            | 作用                                                         | 是否重要 | 是否适合你现在学                  |
| --------------- | ------------------------------------------------------------ | -------- | --------------------------------- |
| `transform/`    | **核心编译流程控制**模块，包含模型转换流程（ONNX→MLIR→BModel） | ✅核心    | ✅**必须学！重点！**               |
| `tpu_mlir/`     | 一些封装类和平台配置（比如不同芯片BM1684X、BM1688等支持）    | ✅重要    | ✅建议了解                         |
| `tools/`        | 包含 `model_transform.py` 等工具，是用户真正运行的主程序     | ✅核心    | ✅**必须学！就是你用的命令行工具** |
| `utils/`        | 工具类模块，辅助操作，比如 shape 推理、模型信息提取等        | ⚠️辅助    | ✅逐步了解                         |
| `mlir_ast/`     | 封装了 MLIR IR 的 Python 表达形式，用于构造/分析 IR          | ⚠️中高级  | ❌暂时跳过                         |
| `numpy_helper/` | 用于加载和保存 numpy/onnx 的张量数据                         | ⚠️辅助    | ✅转换模型时会接触                 |
| `samples/`      | 一些使用例子                                                 | ⚠️可选    | ✅有助于理解流程                   |

| 目录              | 作用                                | 是否重要  | 是否适合入门学        |
| ----------------- | ----------------------------------- | --------- | --------------------- |
| `calibration/`    | 用于量化校准流程，如 INT8 精度校准  | ✅重要     | ❌入门先跳过           |
| `debugger/`       | 调试器，支持模型在各层中间检查      | ✅实用     | ❌先跳过，后面可以练习 |
| `eval/`           | 评估工具（比如精度、性能评估）      | ✅重要     | ❌可以晚一点看         |
| `PerfAI/`         | AI 性能分析工具（分析不同层的耗时） | ✅高级功能 | ❌后期再学             |
| `profile_helper/` | profile 数据分析辅助                | ✅高级     | ❌跳过                 |
| `test/`           | 测试模块                            | ⚠️中等     | ✅可作为参考使用       |

**推荐学习路径**

| 阶段  | 推荐学习目录               | 说明                                                   |
| ----- | -------------------------- | ------------------------------------------------------ |
| 第1步 | `tools/model_transform.py` | 整个模型转换流程的入口，是你平时用的脚本               |
| 第2步 | `transform/`               | model_transform 依赖这里的逻辑，如前处理、转换、量化等 |

# 3、 Python的Transformer代码学习

这部分代码是从原始模型转换成onnx的关键一步

| 文件名                   | 功能说明                                                     | 是否重要    | 是否适合现在学习                   |
| ------------------------ | ------------------------------------------------------------ | ----------- | ---------------------------------- |
| `BaseConverter.py`       | 所有框架转换器的 **基类**，定义了通用接口，如 `run`, `gen_mlir`, `gen_weight` 等 | ✅非常重要   | ✅**必须了解，推荐第一顺位**        |
| `OnnxConverter.py`       | **ONNX → MLIR** 的主要转换器，实现了将 ONNX 模型转为 MLIR IR 的过程 | ✅非常重要   | ✅**适合新手第一阶段学习**          |
| `MLIRImporter.py`        | 封装了 MLIR 构建的 Python 接口，比如如何生成 Operation、Block、Value 等 | ✅重要       | ✅建议结合 OnnxConverter 一起学习   |
| `TorchConverter.py`      | **PyTorch → MLIR** 的转换器（通过 torchscript 或 fx）        | ✅重要       | ⭕感兴趣可学，但建议晚于 ONNX       |
| `TFLiteConverter.py`     | **TFLite → MLIR** 的转换器                                   | ✅重要       | ⭕如果你用 TFLite，可以学习         |
| `CaffeConverter.py`      | **Caffe → MLIR** 转换器（较老）                              | ⚠️有限使用   | ❌新手不建议优先看                  |
| `MaskRCNNConverter.py`   | 针对 MaskRCNN 的专用优化转换器（特别模型定制）               | ⚠️专用       | ❌跳过，暂不适合                    |
| `TorchHelper.py`         | 提供辅助函数，如 shape 推理、类型处理，用于 Torch 转换器     | ⚠️辅助       | ⭕先不用看                          |
| `TorchInterpreter.py`    | 用于模拟运行 torch 模型并提取结构、shape 等信息              | ⚠️工具类     | ❌跳过                              |
| `TFLiteInterpreter.py`   | 同上，适用于 TFLite 模型解释与辅助转换                       | ⚠️工具类     | ❌跳过                              |
| `OnnxOpOptionalAttrs.py` | 定义了一些 ONNX Op 的**可选属性默认值**（避免属性缺失导致失败） | ⚠️次重要     | ⭕学习 OnnxConverter 时可以顺便看看 |
| `OnnxOpt.py`             | 对 ONNX 做一些前置优化，比如合并节点、常量折叠               | ⚠️重要但独立 | ✅可作为 ONNX 流程的补充学习        |
| `TpuLangConverter.py`    | 将模型转换为 TpuLang IR（TPU 可执行 IR 的一种中间形式）      | ✅重要       | ❌等你理解 MLIR 再来学              |
| `TpuLang.py`             | 定义 TpuLang 中使用的语义、结构、Op 表示                     | ⚠️结构定义   | ❌先跳过                            |
| `tflite_schema.fbs`      | TFLite 模型结构定义文件（FlatBuffers 描述）                  | ⚠️底层格式   | ❌不用管，TFLite 用才有用           |

**建议学习路径**

| 推荐顺序 | 文件名                      | 原因                                             |
| -------- | --------------------------- | ------------------------------------------------ |
| ①        | `BaseConverter.py`          | 所有框架转换器都继承它，理解结构非常关键         |
| ②        | `OnnxConverter.py`          | 最常用的 ONNX 转换流程入口，适合先学             |
| ③        | `MLIRImporter.py`           | 理解如何在 Python 中构建 MLIR IR                 |
| ④        | `OnnxOpt.py`                | 了解转换前对 ONNX 的优化流程                     |
| ⑤        | `OnnxOpOptionalAttrs.py`    | 支持默认属性值填补，配合 `OnnxConverter.py` 使用 |
| ⑥        | （扩展）`TorchConverter.py` | 如需支持 PyTorch，可继续学习                     |
