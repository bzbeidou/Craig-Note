### 1、Pattern是什么？

 `get_matched_patterns(log_file)` 返回的是什么？

假设你打开了 `count_patterns=True`，那么：

```py
matched = get_matched_patterns("tpu_patterns.log")
print(matched)
```

可能会返回一个像这样的字典（示意）：

```
{
  "FoldAddToBias": 12,
  "ConvReluFusion": 8,
  "LoweringTopToTpuOp": 56,
  "RemoveRedundantOps": 9,
  ...
}
```

含义是

| 模式名称             | 匹配次数 |
| -------------------- | -------- |
| `FoldAddToBias`      | 12 次    |
| `ConvReluFusion`     | 8 次     |
| `LoweringTopToTpuOp` | 56 次    |
| `RemoveRedundantOps` | 9 次     |

表示在整个 MLIR lowering 流程中，这些优化重写规则被**应用了多少次**。

`get_matched_patterns(log_file)` 就像是在告诉你“有哪些优化发生了、发生了几次”，方便你评估你的模型是否被正确且充分地编译优化了
