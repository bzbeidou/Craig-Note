### 遇到问题

- 同学传到了upstream的main分支
- 我没有pull分支，所以是上一个版本的分支
- 我们两个同时开发了同一个文件
- 导致冲突



### 解决方案

- 我先pull到我自己的main分支上
- 因为我的main分支完全是依赖upstream的main分支
- 所以pull完全没问题
- 然后到我的rsqrt分支上执行`git merge main`
- 将我的main分支内容merge到我的rsqrt时会提示有冲突
- 因为我再rsqrt分支进行的开发
- 将冲突解决就可以了

### 第一步：确认冲突文件

冲突集中在这几个文件：

- `aiacc/SMI_IQ/Makefile`
- `aiacc/SMI_IQ/app/tvgen.cpp`
- `aiacc/SMI_IQ/app/tvgen_core.cpp`

用 `git status` 再确认一遍：

```
git status
```

------

### 第二步：手动解决冲突

1. 冲突文件

	```
	<<<<<<< HEAD
	# 这是你的rsqrt分支里的代码
	=======
	# 这是main分支里的最新代码
	>>>>>>> main
	```

2. 决定保留的内容

	你需要根据业务逻辑，选择保留哪一部分，或者将两者的代码整合。

	- 比如在 `Makefile` 中，如果上游添加了新的编译依赖，而你添加了新的编译目标，就需要把两者都保留。

3. 删除冲突标记

	整理完代码后，删除 

	```
	<<<<<<< HEAD
	=======
	>>>>>>> main
	```

	 这些标记，保存文件。
