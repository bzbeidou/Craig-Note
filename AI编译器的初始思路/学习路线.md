**大致路线就是**

**pytorch->tvm->cuda/llvm**

实际上这也是整个的模型运行到硬件的全流程



#### pytorch 

1. **张量基础**
	- 创建张量：`torch.tensor()`, `torch.zeros()`, `torch.randn()`
	- 张量操作：索引、切片、广播、reshape
2. **GPU 张量**

  - `.cuda()` 将张量放到 GPU
  - 观察 GPU 内存占用

- **构建神经网络模型**

1. **nn.Module 基本用法**
	- 定义简单 CNN / MLP
	- forward 方法实现前向传播
2. **训练基础**
	- 定义 loss / optimizer
	- 前向 + 反向传播
3. **实践实验**
	- 训练一个小数据集（如 MNIST/CIFAR-10）
	- 打印每层输出形状
	- 用 `torch.profiler` 分析每个算子耗时

- 理解计算图结构，能导出 IR

1. **动态图（Eager Execution）**
	
	- forward 每次即时执行
	- 调试容易
	
2. **TorchScript / tracing**
	- `torch.jit.trace` / `torch.jit.script` 导出静态计算图
	
		

1. **CUDA 张量操作**
	- 张量移动：`.cuda()` / `.to(device)`
	- 操作并行性：矩阵乘法、卷积
2. **性能分析**
	- `torch.profiler` + NVIDIA Nsight 或 nvidia-smi
	- 观察 kernel launch、显存占用、并行效率
3. **实践实验**
	- 编写一个卷积层，测不同 batch size / input size 的性能
	- 对比 CPU/GPU 性能差异

- **PyTorch 与编译器结合**

1. **导出 ONNX**
	- `torch.onnx.export(model, input, "model.onnx")`
2. **导入 TVM**
	- 用 TVM Frontend 将模型转成 Relay IR
	- 查看每个算子
