#### 1、高层

编译器负责定义这个算子的语义

```mlir
%y = mydialect.conv2d(%x, %w)
```

在 TableGen 里

```
def MyConv2DOp : Op<"mydialect.conv2d", ...> {
  let arguments = (ins Tensor:$input, Tensor:$weight);
  let results = (outs Tensor:$output);
}
```

**告诉编译器：“我有一个卷积算子，它有输入、权重、输出。”**

还没涉及怎么算。



#### 2、中层

编译器会（lower）成更底层的实现，比如到了tpu层

```mlir
%y = tpu.conv2d_int8(%x_q, %w_q, %scale, %zp)
```

根据数据类型（float / int8）和硬件平台（CPU / GPU / TPU）决定选哪个 kernel。所以到了这层就相当于已经做好准备用当前的内容去调用底层的kernel了。



#### 3、底层

真正干计算的

```cpp
// INT8 卷积  (C++/汇编)
void conv2d_int8_kernel(const int8_t* input, const int8_t* weight, int32_t* output, ...) {
    for (int oc = 0; oc < out_channels; ++oc)
        for (int ic = 0; ic < in_channels; ++ic)
            output[oc] += input[ic] * weight[oc][ic];
}
```
