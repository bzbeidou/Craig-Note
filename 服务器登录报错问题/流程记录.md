服务器上使用 VSCode Remote SSH 登录 Codex 时出现错误：

```
Sign-in could not be completed
Token exchange failed
error sending request for url (https://auth.openai.com/oauth/token)
```

在服务器测试网络：

```
curl -I https://api.openai.com
```

报错：

```
OpenSSL SSL_connect: SSL_ERROR_SYSCALL
```

说明服务器无法直接访问 OpenAI。

所在网络（如校园网 / 企业网）对 OpenAI 进行了限制：

- DNS 重定向
- TLS 拦截
- 防火墙限制

导致服务器无法访问：

```
api.openai.com
auth.openai.com
```

但本机电脑可以正常访问 OpenAI。

因此解决思路是：服务器挂vpn本机代理

解决思路

通过服务器 **服务器挂vpn端口转发（Reverse Tunnel）**

重新连接 VSCode

步骤：

1. VSCode 断开 Remote SSH
2. 重新连接服务器
3. 再次登录 Codex

此时：

```
VSCode Server
      ↓
127.0.0.1:1082
      ↓
SSH隧道
      ↓
本机代理
      ↓
OpenAI
```

登录即可成功。

优化（自动建立隧道）

避免每次手动执行 `ssh -R`。

编辑本机 SSH 配置：

```
C:\Users\sherlock\.ssh\config
```

以后只需要：

```
VSCode → Remote SSH → bupt-server
```

SSH 会自动建立代理隧道。

安全性说明

此方案安全性较高，因为：

- SSH 隧道是加密的
- 端口绑定在 `127.0.0.1`
- 只影响当前用户 `craig`
- 不修改服务器系统配置
- 不影响其他用户

仅改变：

```
/home/craig/.vscode-server
/home/craig/.bashrc
```

属于用户级配置。

常见问题

SSH 隧道断开

如果 SSH 终端关闭：

```
1082端口消失
```

代理失效。

解决：

- 保持 SSH 会话
- 或使用 `.ssh/config` 自动转发

代理端口变化

如果本机代理端口改变，例如：

7897 → 7890

只需修改
