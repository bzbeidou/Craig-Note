**没有在自己的代码里显式调用**接口方法，也必须实现，这是 **C++ 链接器和 MLIR 生成机制的“要求”**，原因如下：



### 1、 生成的模板调用

 `A16MatMulOp` 声明了接口

```tablegen
let interfaces = [DeclareOpInterfaceMethods<InferenceInterface>];
```

模板代码：

```c++
namespace tpu_mlir {
namespace detail {

template <>
struct InferenceInterfaceInterfaceTraits::Model<A16MatMulOp> {
  static void inference(Concept const *concept, mlir::Operation *op,
                        InferenceParameter &p) {
    cast<A16MatMulOp>(op).inference(p);  
  }
};

} // namespace detail
} // namespace tpu_mlir
```

### 2、链接

链接 **不会区分你“是否真的运行到这个函数”**，只要模板里生成了调用，就必须有对应符号。
