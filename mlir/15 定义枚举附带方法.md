### 生成的方法

- symbolize
 - symbolizeState，symbolizeEnum

`symbolizeState(uint32_t)`

 `symbolizeState(::llvm::StringRef)`

```c++
::std::optional<State> symbolizeState(uint32_t);
::std::optional<State> symbolizeState(::llvm::StringRef);

```

- 输入一个 `uint32_t`返回对应的枚举值（比如 `State::Top_CALIBRATED`）。如果输入数字不合法，返回 `std::nullopt`。

- `"TPU_LOWERED"`,返回枚举 `State::TPU_LOWERED`,如果字符串不合法，返回 `std::nullopt`

 `symbolizeEnum` 

```c++
template <typename EnumType>
::std::optional<EnumType> symbolizeEnum(::llvm::StringRef);
```

- 这是个 **模板函数声明**，支持“泛型枚举字符串化”。
- 默认实现为空。

然后针对 `State` 做了一个特化：

```c++
template <>
inline ::std::optional<State> symbolizeEnum<State>(::llvm::StringRef str) {
  return symbolizeState(str);
}
```

```
auto st = symbolizeEnum<State>("TPU_LOWERED");
```

 `stringifyState(State)`  返回对应的字符串 `"TPU_LOWERED"`。

 `stringifyEnum`

这是一个转接函数。内部直接调用 `stringifyState`。

所有枚举类都能用统一名字 `stringifyEnum`，而不是每个枚举都写 `stringifyXXX`
