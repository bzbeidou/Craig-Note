### 3、决定用哪个

框架在 `Arch::init()` 里，这就是初始化的Pass里会调用

```c++
if (chip == module::Chip::BM1684) {
    inst = &BM1684::instance();
} else if (chip == module::Chip::CV186X) {
    inst = &CV18xx::instance(chip);
}
```
