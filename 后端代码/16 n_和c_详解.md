## 2 代码解析

### （1）每个tile的宽度是多少

- 这里h一般传入1
- 假设w = 4，eu = 16
- 这里w = 4但是实际上一行确实要占用16个元素的位置
- 所以这是一种浪费，建议切分时tile = 16这样子（我自认为）

```c++
INLINE static int get_local_cstride(int h, int w, bool align, PREC precision) {
  return align ? ALIGN(h * w, get_eu_num(precision)) : (h * w); 
}

#define ALIGN(x, a) (((x) + (a) - 1) / (a) * (a))
```

#### （2）n_stride 原矩阵的一行放到每个npu的locmem之下占用多少个元素空间位置（并非）

**这里的讲解是错的**

- 假设原矩阵一行有10个元素，即宽度为10，那么切分按照4来的换就是切3份
- 假设一共有64个npu
- 我们看第一行，
- 但是实际上需要按照EU的规则来，也就是上面的向上取整
- 所以并不是4 4 2

综上看计算原矩阵一行实际占多少个元素的如下代码：

- 这个函数就是返回原矩阵一行，放到每个npu的locmem里到底占多少
- 这里之所以加上npu的序号是因为不一定从第一个npu开始，所以加上了
- 得到一个多少个tile之后再对npu数量向上取整
- 一共64个npu，那么65对64向上取整就是2，所以原矩阵的一行一共占用了两次总的npu
- 64个tile分别占一个，然后第65个返回来再占一个占到npu0
