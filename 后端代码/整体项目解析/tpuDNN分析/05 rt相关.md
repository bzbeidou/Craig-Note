```c++
template <class DevicePolicy, class BMLibMemoryPolicy>
class BMLibRuntime : public BMLibMemoryPolicy
{
private:
    int mDeviceID;
    bm_handle_t mHandle;
    tpu_kernel_module_t mModule;
    bool mIsStreamBorrowed;

protected:
    ~BMLibRuntime()
    {
        if (!mIsStreamBorrowed)
        {
            tpu_kernel_unload_module(mHandle, mModule);
            bm_dev_free(mHandle);
        }
    }

public:
    using Launcher = BMLibLauncher<DevicePolicy>;

    BMLibRuntime(int deviceID) : mDeviceID(deviceID), mModule(nullptr), mIsStreamBorrowed(false)
    {
        auto ret = bm_dev_request(&mHandle, mDeviceID);
        if (BM_SUCCESS != ret)
        {
            LOG(ERROR) << "Failed to get bmlib device";
            mHandle = nullptr;
        }
    }

    uint64_t malloc(size_t size)
    {
        return BMLibMemoryPolicy::malloc(mHandle, size);
    }

    void free(uint64_t addr)
    {
        return BMLibMemoryPolicy::free(mHandle, addr);
    }

    TPUStream<DevicePolicy, Launcher> createStream(const std::string &fn)
    {
        mModule = tpu_kernel_load_module_file(mHandle, fn.c_str());

        return TPUStream<DevicePolicy, Launcher>({mHandle, mModule});
    }

    TPUStream<DevicePolicy, Launcher> createStream(const void *data, size_t size)
    {
        mModule = tpu_kernel_load_module(
            mHandle, static_cast<const char *>(data), size);

        return TPUStream<DevicePolicy, Launcher>({mHandle, mModule});
    }

    TPUStream<DevicePolicy, Launcher> createStream(void *handle, void *module)
    {
        mHandle = reinterpret_cast<decltype(mHandle)>(handle);
        mModule = reinterpret_cast<decltype(mModule)>(module);
        mIsStreamBorrowed = true;

        return TPUStream<DevicePolicy, Launcher>({mHandle, mModule});
    }

    static bool useDynLoading() { return true; }

    #define BMLIB_RUNTIME
    #include "bmlib_dummy_function.h"
    #undef BMLIB_RUNTIME

};

template <class DevicePolicy>
using DefaultBMLibRuntime = BMLibRuntime<DevicePolicy, BMLibMemory>;
```



# **1. 策略+ 内存组合**

```
template <class DevicePolicy, class BMLibMemoryPolicy>
class BMLibRuntime : public BMLibMemoryPolicy {
```

这意味着：

- `DevicePolicy`表示芯片
- `BMLibMemoryPolicy`内存

而本类继承了内存策略类：

```
public BMLibMemoryPolicy
```

可以通过不同的内存策略类来改变内存管理方式。

------

#  **2. 成员**

```
private:
    int mDeviceID;
    bm_handle_t mHandle;
    tpu_kernel_module_t mModule;
    bool mIsStreamBorrowed;
```

作用：

| 成员                | 作用                                       |
| ------------------- | ------------------------------------------ |
| `mDeviceID`         | 选择哪块 TPU 卡                            |
| `mHandle`           | bmlib 的设备句柄（类似 CUDA 的 CUcontext） |
| `mModule`           | 加载的 kernel module 句柄                  |
| `mIsStreamBorrowed` | stream 是否来自外部（比如框架传进来的）    |

------

#  **3. 析构函数**

```
~BMLibRuntime() {
    if (!mIsStreamBorrowed) {
        tpu_kernel_unload_module(mHandle, mModule);
        bm_dev_free(mHandle);
    }
}
```

解释：

- 如果 stream 是内部创建的 → 释放 module，释放 device handle
- 如果是外部借来的 → 不操作（避免误删）

即：Runtime 负责资源生命周期管理，但不会擅自删除不属于它的资源。

------

#  **4. 构造函数：申请 TPU 设备**

```
BMLibRuntime(int deviceID)
    : mDeviceID(deviceID), mModule(nullptr), mIsStreamBorrowed(false)
{
    auto ret = bm_dev_request(&mHandle, mDeviceID);
    if (BM_SUCCESS != ret) {
        LOG(ERROR) << "Failed to get bmlib device";
        mHandle = nullptr;
    }
}
```

对应 bmlib API：

| bmlib 功能       | 解释                                            |
| ---------------- | ----------------------------------------------- |
| `bm_dev_request` | 打开 TPU device，返回一个句柄                   |
| `mHandle`        | 后续所有 malloc, memcpy, launch kernel 都依赖它 |



------

#  **5. 内存管理接口封装**

```
uint64_t malloc(size_t size) {
    return BMLibMemoryPolicy::malloc(mHandle, size);
}

void free(uint64_t addr) {
    return BMLibMemoryPolicy::free(mHandle, addr);
}
```

注意：这里完全把 malloc/free 功能委托给 BMLibMemoryPolicy。

也就是说：

- 如果你换成 another memory policy，就能切换真正的 memory 管理策略。

这种结构是典型的模板策略模式 。

# **6. createStream**



```
TPUStream<DevicePolicy, Launcher> createStream(const std::string &fn) {
    mModule = tpu_kernel_load_module_file(mHandle, fn.c_str());
    return TPUStream<DevicePolicy, Launcher>({mHandle, mModule});
}
```

1. 从一个 .bmodel文件加载 TPU kernel module
2. 得到 module handle
3. 构造 TPUStream（流），用于 kernel 调度

```
createStream(const void *data, size_t size)
```

用于：

- 直接从内存 buffer 加载 kernel module

```
createStream(void *handle, void *module)
```

用于：

- 外部系统把 handle 和 module 传入
- runtime 不负责释放

# 7. useDynLoading 固定返回 true

说明：BMLibRuntime 支持动态加载 TPU kernel module

# **8. 注入 bmlib dummy 函数**

```
#define BMLIB_RUNTIME
#include "bmlib_dummy_function.h"
#undef BMLIB_RUNTIME
```

作用：如果某些 bmlib API 在当前平台不可用，则替换为 dummy 实现。

例如：cmodel 模式下没有真实 DMA copy → dummy 版本只做 memcpyhost 只执行部分 kernel → dummy 版本跳过硬件指令

# **三、最后那一行 typedef 代表什么？**


**DefaultBMLibRuntime 底层内存策略。**

而 BMLibMemory 就是：调用 `bm_malloc_device`调用 `bm_free_device`调用 `bm_memcpy_xxx`

真实 TPU 硬件环境使用的 memory 管理类。
