```
#define ALIGN(x, a) (((x) + (a) - 1) / (a) * (a))
```

```
ALIGN(20, 16)  → 32
ALIGN(33, 16)  → 48
ALIGN(64, 16)  → 64
```

给定任意整数 **x**（比如 20）
 比如 a = 16：

```
x = 20 → 16 
x = 17 → 16 
x = 32 → 16 
```

想要的就是：

```
ALIGN(x, a) = ⌈x / a⌉ * a
```

ceiling

**向上取整，再乘回 a**

数学上我们要：

```
ALIGN(x, a) = ceil(x / a) * a
```

```
20 / 16 = 1      （向下取整）
17 / 16 = 1      （向下取整）
```

我们需要人为补偿，让它“向上取整”。

理解 `(x + a - 1) / a` 为什么是向上取整

情况1：当 x 刚好是倍数时

例如 x = 32, a = 16：

```
(x + a - 1) / a
= (32 + 15) / 16
= 47 / 16 = 2 （整除）
而 32 / 16 = 2（也对）
```

```
(x + a - 1) / a
= (20 + 15) / 16
= 35 / 16
= 2（向下取整）
```

 (a - 1) 

原因是：

```
任何未对齐的值，在加上 (a - 1) 后，都至少提升到下一个 a 的倍数的区间。
```

比如：

```
20 + 15 = 35  落入 16*2 的区间(32~47)
17 + 15 = 32  正好变成下一个倍数
31 + 15 = 46  落入第二个区间(32~47)
```
