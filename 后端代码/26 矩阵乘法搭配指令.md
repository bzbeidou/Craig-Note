 **操作类型、模式、ID、控制类信息**。

```
low = (1ull)                           // enable
    | (bd_cmd_id << 1)
    | (gdma_cmd_id << 21)
    | (MM << 41)                       
    | (MM_NORMAL << 45)                
    | (add_result << 50)
    | (is_L_trans << 51)
    | (is_L_const << 52)
    | (is_bias_const << 53)
    | (1ull << 55);                    

high = (FP32 << 3)                    
      | (FP32 << 6)                  
```

**任务的基本信息**。

 **矩阵维度信息（shape + layout）**。

```
low = R_tensor_W                       
    | (L_col_num/L_row_num << 16)     
    | (L_tensor_C << 32)              
    | (L_tensor_W << 48);             

high = (L_last_W << 16)
     | (Y_addr << 32);               
```



```
low = L_addr | (R_addr << 32);         
high = bias_addr;                   
```

硬件设计时，会定义：

- BD 指令需要几条
- 每条 128bit
- 每个 bit 段存的含义是什么

| bit 段范围 | 字段名        | 说明                       |
| ---------- | ------------- | -------------------------- |
| 0          | enable        | 启动位                     |
| 1 ~ 20     | bd_cmd_id     | BD 的唯一指令号            |
| 21 ~ 40    | gdma_cmd_id   | 配套的 GDMA 指令号         |
| 41 ~ 44    | op_type       | 操作类型，如 MM、CONV、ADD |
| 45 ~ 49    | mm_mode       | 普通/Winograd 等模式       |
| 50         | add_result    |                            |
| 51         | is_L_trans    |                            |
| 52         | is_L_const    |                            |
| 53         | is_bias_const |                            |
| 55         | last_flag     |                            |

| bit 范围       | 字段                     |
| -------------- | ------------------------ |
| 0 ~ 15         | R_tensor_W               |
| 16 ~ 31        | L 的列或行数（根据转置） |
| 32 ~ 47        | L_tensor_C               |
| 48 ~ 63        | L_tensor_W               |
| 16 ~ 31 (high) | L_last_W                 |
| 32 ~ 63 (high) | 输出 Y 的地址高位        |

| bit 範圍 | 字段      |
| -------- | --------- |
| 0 ~ 31   | L_addr    |
| 32 ~ 63  | R_addr    |
| 0 ~ 63   | bias_addr |
