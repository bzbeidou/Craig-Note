这里就是 **C++ 的函数模板 + 特化 + 封装** 用法，让 `mm_gen_data` 能够根据不同数据类型生成随机矩阵元素，**当然不止是生成随机矩阵，所有生成随机元素的方式都可以这样**。

1 **模板版本（泛型）**

```
template<typename T>
void mm_gen_data(T* data, int len) {
  for (int i = 0; i < len; i++) {
    data[i] = (T)((rand() % 255) - 128);
  }
}
```

- **作用**：生成整数类型的随机数据（默认假设是 8/16/32 位整数类型）
- **原理**：
	- `rand() % 255` → `[0, 254]`
	- `-128` → `[-128, 126]`
	- `(T)` → 强制类型转换到模板类型 `T`
- **适用场景**：INT8、INT16、INT32 等整数类型数据

> 示例：

```
char data[5];
mm_gen_data(data, 5); 
// 可能生成 [-128, -50, 0, 23, 100] 之类的随机整数
```

2 **float 特化版本**

```
template<>
void mm_gen_data(float* data, int len) {
  for (int i = 0; i < len; i++) {
    data[i] = ((float)rand() / (float)RAND_MAX) * 3.3;
    if (rand() % 2) data[i] = -data[i];
  }
}
```

- **作用**：专门处理 FP32 类型（浮点数）
- **原理**：
	1. `rand() / RAND_MAX` → `[0,1)`
	2. `* 3.3` → `[0,3.3)`
	3. 随机加负号 → `[-3.3, 3.3)`
- **适用场景**：FP32 矩阵

> 这是一个 **模板特化**（`template<>`），告诉编译器 “如果 T 是 float，用这个版本，而不是默认模板”。

3 **void\* 封装版本**

```
void mm_gen_data(void* data, int len, PREC prec) {
  if (prec == FP32) mm_gen_data((float*)data, len);
  else if (prec == INT8) mm_gen_data((char*)data, len);
  else if (prec == INT16) mm_gen_data((short*)data, len);
  else if (prec == INT32) mm_gen_data((int*)data, len);
}
```

- **作用**：根据精度 `PREC` 调用对应类型的生成函数

- **原理**：

	1. `void*` 是泛指指针，不知道具体类型
	2. 根据 `prec` 转换成具体类型指针
	3. 调用模板或特化版本生成随机数据

- **好处**：

	- 上层代码不用关心类型，统一调用：

		```
		mm_gen_data(L_ptr, rows*cols, param.LR_prec);
		```

	- 内部会自动根据 FP32/INT8/INT16/INT32 生成随机数据
