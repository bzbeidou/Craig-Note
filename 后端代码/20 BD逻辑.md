##  BD

在 TPU/AI 芯片后端：

- 它是 **一条指令的最小描述单元**，通常包含：
  - 操作类型（矩阵乘法 / 卷积 / 激活等）
  - 数据类型（FP32/INT8）
  - 是否转置 / 是否累加
  - 数据地址（输入矩阵 L/R，输出矩阵 Y，偏置）
  - 矩阵维度、tile 信息
- 硬件执行器（比如 DMA + Matrix Engine）按 **BD 流**读取参数，执行矩阵乘法。

- 实际上，C++ 没有 “BD 类型”，它只是 **内存中的一块 64-bit 数据数组**。
- 举例：

```
u64 high = 0x0000000000000001;
u64 low  = 0x1000000000000000;
WRITE_CMD_BD(0, high, low);
```
