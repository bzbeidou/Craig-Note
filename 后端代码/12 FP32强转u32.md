

```c++
void mm_trans(void* src, void* dst, int row, int col, PREC prec) {
  for (int i = 0; i < row; i++) {
    for (int j = 0; j < col; j++) {
      if (prec == FP32 || prec == INT32) {
        ((u32*)dst)[j * row + i] = ((u32*)src)[i * col + j]; // 这里为什么FP32强转成u32？ 没问题，长度相同
      } else if (prec == INT8) {
        ((u8*)dst)[j * row + i] = ((u8*)src)[i * col + j];
      } else if (prec == INT16) {
        ((u16*)dst)[j * row + i] = ((u16*)src)[i * col + j];
      }
    }
  }
}
```



这里仅仅是进行数据的搬运，并不涉及真正的类型转换

**代码行为**

```
((u32*)dst)[j * row + i] = ((u32*)src)[i * col + j];
```

- 把 `float*` 强制转换为 `u32*`
- 其实 **只是按 4 字节单元搬运内存**
- 这里并没有做浮点到整数的数值转换
- 对于内存搬运和转置来说，只要 **数据宽度相同**，类型并不影响内存拷贝

理论上可以写成：

```
((float*)dst)[j * row + i] = ((float*)src)[i * col + j];
```

- 功能上等价
-  可能是为了 **统一 INT32 和 FP32 的内存搬运逻辑**
- 这样模板或者函数就可以同时处理 FP32、INT32，少写代码分支
