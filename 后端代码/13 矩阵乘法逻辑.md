- 推算一下放数组的话怎么存
- 就能直接写出来了

**注意：** 这里是外层是k，然后内层是i和j。但是不管是怎么排都是正确的，

常见的两种方式（从外到内）就是： i，j，k      k，i，j

```c++
void native_mm_core_fp32(MM_PARAM* param, float L_const_val, float opd2_const_val,
    float* L_ptr, float* R_ptr, float* bias_ptr, float* Y_ptr)
{
  for (int kidx = 0; kidx < param->L_col_num; kidx++) {
    for (int ridx = 0; ridx < param->L_row_num; ridx++) {
      for (int cidx = 0; cidx < param->R_col_num; cidx++) {
        Y_ptr[ridx * param->R_col_num + cidx] +=
            (param->is_L_const ? L_const_val : L_ptr[ridx * param->L_col_num + kidx])
            * R_ptr[kidx * param->R_col_num + cidx];
      }
    }
```
