**实际上这里返回的是一个元素的数量，下面的讲解是算上了每个数据的字节大小**

- 20个FP32元素(4*5)，EU能处理是16个，
- EU不针对具体数据类型下的宽度
- 存放问题，20个FP32就是`20*4`byte，那么要直接占据`20*4`个byte的local内存
- 那么分配的空间也就是`16*2*4`
- 16代表EU一次能处理多少个FP32数据
- 需要分配`16*2*4 = 128`byte的localmem，没有数据的地方就补0

```c++
INLINE static int get_local_cstride(int h, int w, bool align, PREC precision) {
  return align ? ALIGN(h * w, get_eu_num(precision)) : (h * w);
}
```
