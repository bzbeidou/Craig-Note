## 宏拼接符`##`，常用在变量名的拼接

在宏里使用，当宏展开的时候会自动拼接

- 例子：

```
#define MAKE_VAR(name) int var_##name = 0;
MAKE_VAR(foo);
```

展开为：

```
int var_foo = 0;
```

- 在你这个例子里, 这里engine是传入的宏参数（宏参数没类型，随便传）：

```
engine##_GEN_CMD
```

- 如果 `engine = BD` → `BD_GEN_CMD`，调用这个宏
- 如果 `engine = GDMA` → `GDMA_GEN_CMD`，调用这个宏

这就是宏参数动态选择命令生成器实例的方式。
