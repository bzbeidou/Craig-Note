标准时间戳函数和随机数产生函数

```c++
int mm_random_test()
{
  static int entry = 0;
  entry++;
  u32 seed = time(NULL) + entry * 20000;
  srand(seed);
```

## 1  `time`

- **当前时间戳**
- 只返回当前时间戳，不把结果存到别的变量
- 类型是 `time_t`（通常是 `long` 或 `long long`）

```
time_t t = time(NULL);
printf("%ld\n", t);
```

输出

------

## 2 静态计数器

- 每次 `mm_random_test()` 被调用都会加 1
	1. **每次产生不同的随机种子**
	2. 避免 精度过低（秒级），导致连续调用随机数相同



```
entry = 1; seed = time(NULL) + 1*20000;
entry = 2; seed = time(NULL) + 2*20000;
```

------

## 3 随机数生成器

- 用来初始化 C 标准库的随机数生成器
- 之后调用 `rand()` 

```
srand(1234);  
int x = rand(); 
```

- 保证每次测试随机，但又可复现



##   函数原型

- 参数 `t` 是 **一个指向 `time_t` 类型的指针**
- 传了一个指针，它会把当前时间写到你提供的变量里
- 返回值单位是秒

```
time(NULL)
```

-  **我不需要写到任何变量里**
