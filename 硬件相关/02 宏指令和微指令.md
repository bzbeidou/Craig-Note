指令就是芯片涉及人员给规定的指令

编译器编译的结果就是宏指令，而不是微指令。

- 宏指令叫做ISA级指令（指令集架构）， 微指令则是内部的 micro-op

- 宏指令简短，每条指令代表很多数据，与算子强相关
- 微指令很多，与算子并不强相关，反而与SMC硬件架构相关

### 1宏指令

**是 AIACC 对外暴露的“编程接口级指令”**，用于描述：

- 一个算子
- 或一个计算阶段
- 或一个数据搬运阶段

举例（抽象化）（具体应该是二进制的形式，每几位代表什么信息，规定的）

```c++
MACRO_EXP:
  src_addr = A
  dst_addr = B
  length   = 1024
  dtype    = FP16
```

**假设这条EXP的宏指令128位，那么可能32位代表src_addr， 32位代表ast_addr，16位代表length，50位代表dtype这样子（胡说的）**

这条宏指令的含义是：“对 A 中的 1024 个 FP16 元素，做 exp 运算，结果写到 B”



### 2微指令

**微指令是宏指令在硬件内部被拆解后的最小执行控制单元**。

直接驱动：SMC 计算单元，LSU，寄存器文件，pipeline stage

**就是更为细致的指令**

**通过MID即可将宏指令转成微指令**

### 3 宏指令和微指令都是二进制  只不过命令条数不同，而且每条命令的字节数不同

- **编译器负责：**
	- 把高层 IR → 宏指令 → **宏指令二进制**
- **硬件MID负责：**
	- 把宏指令二进制 → 微指令二进制 → 执行
